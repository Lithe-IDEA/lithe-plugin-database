## 中文

Lithe Database 0.1.2（macOS，Apple silicon / Intel 通用）接入 Lithe 的结构化插件诊断（`litheLogging` 1）。这是预发布版本：需要提供 `litheLogging` 1 的 Lithe preview 开发版，稳定版 Lithe 0.6.7 能安装但无法启动后端，请在稳定版上继续使用 Lithe Store 中的 0.1.1。

### 改进

- 后端改用官方 Rust SDK 的结构化日志，诊断写入 Lithe 日志窗口中本次会话的 `plugins/io.github.lithe-idea.database/host` 通道。
- 每个后端函数由 SDK 记录唯一的成功或失败终态，带函数 ID、耗时和稳定分类；取消不算失败。
- 工作区加载、历史读写和 DBX 预览的成功不再记 INFO；`database.call` 中元数据、分页浏览和探测类调用只抑制成功记录，显式查询和写入仍记 INFO，所有失败照常记 ERROR。
- 查询结果超过传输上限被裁剪时，每次后端运行只记一次 WARN `result_size_limited`。
- 诊断不含 SQL、连接串、服务器地址、用户名、密码、返回行、配置内容或文件路径；后端启动失败不再向 stderr 打印。
- 官方 Rust SDK 改为仓库内的 vendor 副本，CI 与打包按逐文件 SHA-256 校验。

### 安装与升级

- 预发布版本会被 Lithe Store 自动追踪跳过，暂不收录 Store。下载本版本 ZIP，在「设置 → 插件」的 ⚙ 菜单中选择「从磁盘安装插件…」导入。
- 从磁盘安装的副本不会接收 Lithe 旧内置数据库模块的连接、文件夹、SQL 历史和密码；这次迁移会保留到以后运行从 Lithe Store 安装的副本时再进行。已经在 0.1.1 完成迁移的用户不受影响。
- 权限声明与 0.1.1 相同。
- Release 工作流用 Lithe preview `4dd3165` 的 Core 运行端到端检查，并断言每次调用恰好产生一条日志终态；完整界面交互仍待目标 Lithe 宿主验收。

## English

Lithe Database 0.1.2 for macOS (universal Apple silicon / Intel) adopts Lithe's structured plugin diagnostics (`litheLogging` 1). This is a pre-release: it needs a Lithe preview build that offers `litheLogging` 1. Stable Lithe 0.6.7 installs it but cannot start its backend; keep 0.1.1 from Lithe Store there.

### Improvements

- The backend uses the official Rust SDK's structured logging; diagnostics go to the current session's `plugins/io.github.lithe-idea.database/host` channel in Lithe's log window.
- The SDK records exactly one success or failure for each backend function, with its function ID, duration and a stable category; cancellation is not a failure.
- Successful workspace loads, history reads and writes, and DBX previews no longer log INFO. In `database.call`, metadata, paged browsing and probes suppress only their success entries; explicit queries and writes still log INFO, and every failure logs ERROR.
- When query results are trimmed to the transport limit, one WARN `result_size_limited` is logged per backend run.
- Diagnostics never contain SQL, connection strings, server addresses, user names, passwords, returned rows, configuration content or file paths. Backend startup failures no longer print to stderr.
- The official Rust SDK is vendored in the repository; CI and packaging verify every file's SHA-256.

### Installing and upgrading

- Lithe Store's tracker skips pre-releases, so this version is not listed in the Store. Download this release's ZIP and import it with Install Plugin from Disk… in the ⚙ menu of Settings → Plugins.
- A copy installed from disk does not receive the connections, folders, SQL history and passwords of Lithe's former built-in database module; that move waits until a copy installed from Lithe Store runs. Users who already migrated with 0.1.1 are not affected.
- Permissions are unchanged from 0.1.1.
- The release workflow runs end-to-end checks against Core from Lithe preview `4dd3165`, asserting exactly one terminal log entry per call; complete UI interaction still needs target-host acceptance.
